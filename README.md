# Jelly Terms

Which terms can be collected together? Ten stages, each a little harder:

1. **Pairs**: ten at once. Tap Yes or No under each pair. Yes joins the two jellies for you; a wrong answer turns the card red.
2. **A bunch of jellies**: drag one onto another. Same letter and same power? Squish!
3. Two letters, minus signs, powers, then **locked brackets**: tap the Expand Hammer, then tap a bracket.
4. Powers 3 and 4, then **HARD MODE**: every jelly is the same colour, with many letters. A celebration at the end.
