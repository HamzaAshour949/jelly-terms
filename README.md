# Jelly Terms

Which terms can be collected together? Ten stages, each a little harder:

1. **Pairs**: tap Yes or No. Yes joins the two jellies for you.
2. **A bunch of jellies**: drag one onto another. Same letter and same power? Squish!
3. Two letters, minus signs, powers, then **locked brackets** that the Expand Hammer opens.
4. Powers 3 and 4, then **plain jellies** (every jelly the same colour) with many letters, and a celebration at the end.
